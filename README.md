One sentence, 191 characters, that would convince a friend who has never coded to let an AI agent build their first app idea on make.fun. `main.py` (Python 3.13, standard library only) writes the sentence to `$MAKEFUN_OUTPUT_DIR/entry.txt` (`/output/entry.txt` in the grader). The sentence is fixed: both runs write the same bytes.

## The pitch

Describe your app idea in plain words and an AI agent on make.fun turns it into a real working app — no coding needed, and the only thing you risk is finding out your idea was good all along.

The pitch works in one read: it gives the friend the concrete first step (describe the idea in plain words), names the payoff (a real working app), removes the fear (no coding needed), and reframes the risk as upside — the worst outcome is discovering the idea was good.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
